# Archive 404

A self-contained interactive detective-comedy page with a case board, revealable evidence, a mock intent scan, and branching genre verdicts.

No names, contact details, analytics, forms, third-party assets, or tracking.

## Preview locally

Open `index.html` in a browser or run:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/`.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
